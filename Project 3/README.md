Projek 3 oleh Salsabila Sujarwo

Projek ini adalah sebuah program berbasis console C++ bernama Sistem Inventaris Toko yang dirancang untuk mempermudah manajemen stok barang secara digital dengan memanfaatkan struktur data dinamis struct dan vector agar penyimpanan data bersifat fleksibel tanpa batasan ukuran yang kaku. Alur kerja program dikelola secara modular melalui fungsi-fungsi khusus, meliputi input barang baru yang dilengkapi validasi anti-angka negatif (tambahBarang), pencetakan seluruh daftar aset (tampilkanBarang), pencarian otomatis item dengan harga tertinggi (cariBarangTermahal), kalkulasi akumulasi nilai total modal barang yang mengendap (hitungTotalInventaris), serta sistem pengingat otomatis untuk menyaring item yang stoknya kritis di bawah 5 buah (cekRestock). Selain memiliki validasi data yang kuat, keunggulan teknis dari projek ini adalah penerapan konsep tingkat lanjut berupa Pointer (updateStok) untuk memanipulasi dan memperbarui nilai jumlah stok barang secara realtime langsung pada alamat memori aslinya.
