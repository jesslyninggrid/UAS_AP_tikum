**Project 5: Game Tebak Negara**
Oleh: **Semua anggota kelompok**

Project Tebak Negara merupakan permainan sederhana berbasis C++ yang dirancang untuk menguji pengetahuan pengguna mengenai nama-nama negara di dunia. Program bekerja dengan memilih satu nama negara secara acak dari daftar yang tersedia, kemudian menyembunyikan beberapa huruf pada nama negara tersebut menggunakan karakter underscore (_) sebagai petunjuk bagi pemain. Pengguna diminta menebak nama negara yang dimaksud, dan sistem akan memeriksa kesesuaian jawaban tanpa membedakan huruf besar dan kecil. Setiap jawaban yang benar akan menambah skor pemain, sedangkan jawaban yang salah akan menampilkan pesan kesalahan dan memberikan kesempatan untuk bermain kembali. Dalam pengembangannya, program memanfaatkan **vector** untuk menyimpan kumpulan nama negara, **function** untuk mengelola proses konversi huruf dan penyensoran nama negara, serta **random number generation** untuk memilih soal dan menentukan huruf yang akan disembunyikan secara acak, sehingga permainan menjadi lebih menarik dan bervariasi pada setiap putaran.
