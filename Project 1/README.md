**Project 1 : Parkir Mall Prienal**

Oleh : **Moza Apriza Parinduri (251401020)**


Project ini merupakan program berbasis C++ yang dirancang untuk mengelola sistem parkir mobil secara otomatis di lingkungan mall. Program ini memungkinkan petugas parkir untuk mencatat data kendaraan yang masuk, menampilkan daftar kendaraan yang sedang terparkir, menghitung durasi dan biaya parkir berdasarkan lama waktu kendaraan berada di area parkir, serta memproses pembayaran saat kendaraan keluar. Selain itu, sistem juga menyimpan informasi petugas yang bertugas dan memberikan pemberitahuan apabila kapasitas parkir telah mencapai batas maksimum. Dalam implementasinya, program memanfaatkan **struct** untuk menyimpan data petugas dan kendaraan, **vector** sebagai media penyimpanan data kendaraan secara dinamis, **pointer** untuk mengakses dan memanipulasi data antar fungsi, serta beberapa **function** untuk memisahkan proses pengelolaan parkir sehingga program menjadi lebih terstruktur dan efisien.
